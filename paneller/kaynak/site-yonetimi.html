        GitHub bağlantısı

        Değişiklikleri yayınlamak için GitHub erişim anahtarı gerekir. Evodak Prompt Asistanı ana panelinde Ayarlar'dan bağlandıysanız aynı anahtar burada otomatik kullanılır.

        1. github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
        2. Repository access: yalnızca Evodak-Prompt-Asistan-. Permissions → Contents: Read and write.
        3. Oluşan anahtarı buraya yapıştırıp Bağlan'a basın. Anahtar yalnızca bu tarayıcıda saklanır, hiçbir yere gönderilmez (yalnızca GitHub'a).
